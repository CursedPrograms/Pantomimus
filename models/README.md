# Pantomimus's models

Pantomimus downloads these on the first start into its models folder (Preferences > Models folder), with this
README and the licence beside them. They are not part of the repository.

| File | What | From | Licence |
| --- | --- | --- | --- |
| pose_detection.onnx | BlazePose's person detector (224 x 224) | MediaPipe (Google), ONNX by Unity: huggingface.co/unity/inference-engine-blaze-pose | Apache-2.0 |
| pose_landmarks_detector_lite.onnx | BlazePose's landmarks, lite | the same | Apache-2.0 |
| pose_landmarks_detector_full.onnx | BlazePose's landmarks, full | the same | Apache-2.0 |
| pose_landmarks_detector_heavy.onnx | BlazePose's landmarks, heavy | the same | Apache-2.0 |
| hand_detector.onnx | MediaPipe Hands' palm detector (192 x 192) | MediaPipe (Google), ONNX by Unity: huggingface.co/unity/inference-engine-blaze-hand | Apache-2.0 |
| hand_landmarks_detector.onnx | MediaPipe Hands' 21 landmarks | the same | Apache-2.0 |

LICENSE-Apache-2.0.txt is the licence they come under.
